Ma progression sur 3 ans

Le référentiel BUT Informatique évalue chaque compétence à trois niveaux. Cette page montre comment j'ai évolué Année 1 → Année 2 → Année 3, avec les projets et les prises de conscience associées à chaque étape.

Compétence 1 — Réaliser un développement d'application

Année 1

Premiers développements

Novice — 1/3

Implémentation guidée, peu d'autonomie sur les choix d'architecture.

  • SAE 1.x — Applications Java simples
  • Suivre une spécification, pas encore la concevoir
  • Interfaces basiques, sans prise en compte de l'UX
Année 2

Conception autonome

Intermédiaire — 2/3

Conception d'une solution complète de A à Z, avec justification des choix.

  • MétéoVision — architecture BDD + backend PHP + front JS
  • Premiers choix d'indexation SQL raisonnés
  • Prise en compte de la performance à l'échelle
Année 3

Vision architecturale

Confirmé — 3/3

Architecture multi-composants, adaptation à des contraintes métier réelles.

  • AeroWise — architecture polyglotte (React + 3 bases)
  • Power Apps RATP — conception centrée utilisateur terrain
  • Décisions techniques justifiées face à des parties prenantes non-techniques

Compétence 2 — Optimiser des applications

Année 1

Notions théoriques

Novice — 1/3

Connaissance théorique des complexités algorithmiques, sans application sur données réelles.

  • Complexité O(n), O(n²) — exercices de cours
  • Comparaison d'algorithmes de tri en Java
Année 2

Optimisation en pratique

Intermédiaire — 2/3

Résolution d'un problème de performance réel sur données de production.

  • MétéoVision — diagnostic EXPLAIN SQL, création d'index BTREE
  • Mesure avant/après de la performance des requêtes
  • Compréhension du coût réel des requêtes sans index
Année 3

Optimisation multi-systèmes

Confirmé — 3/3

Optimisation sur des architectures hétérogènes (vectoriel, spatial, graphe).

  • AeroWise — choix des index géospatiaux GiST (PostGIS)
  • Optimisation des embeddings pour la recherche vectorielle (Qdrant)
  • À approfondir : profiling avancé, cache distribué (Redis)

Compétence 4 — Gérer des données de l'information [parcours AGED]

Persistance polyglotte
